# 모바일 달력 날짜 칸 겹침

360px 운영 화면에서 심방 달력 첫 주 버튼의 실제 너비가 44px, 다음 열 시작 간격이 약 37.57px로 측정되어 약 6.43px씩 겹치는 현상을 확인했다. 최소 높이 44px와 정사각형 비율이 자동 너비 계산에 영향을 주었다.

날짜 버튼의 너비와 최대 너비를 그리드 열의 100%로 명시하고 가로 패딩을 제한했다. 높이 44px와 과거 날짜의 옅은 회색은 유지한다. 같은 비율 계산을 사용하는 공통 calendar-cell에도 너비 제한을 적용했다.

운영 배포 후 320px, 360px, 390px 화면에서 날짜 칸이 겹치거나 달력 밖으로 나가지 않는지 실제 DOM 경계로 확인한다.
