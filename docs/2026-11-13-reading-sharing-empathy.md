# 한 줄 나눔 공감

사용자가 작은 하트·숫자 예시 이미지를 확인하고 이 방식으로 구현을 승인했다.

## 동작
- 각 성경통독 한 줄 나눔 아래에 작은 하트와 공감 수를 표시한다. 공감하면 분홍색 하트, 다시 누르면 취소한다. 실제 누르는 영역은 최소 44px이고 보이는 표시는 작게 유지한다.
- 저장은 로그인 세션의 회원 ID를 사용하며 원하는 상태를 PUT한다. 회원/나눔당 1건을 DB 기본키로 보장하고 재시도는 중복 증가 없이 같은 결과를 낸다.
- 공감 대상은 글쓴이 계정과 무관한 날짜별 랜덤 UUID다. 무명 작성자의 실명이나 회원 ID, 공감한 사람 명단은 응답하지 않는다.
- 작성자 비활성화·삭제된 글·다른 날짜의 글은 반영하지 않는다. 삭제와 공감 간 경합은 대상 행 잠금으로 처리한다.
- 나눔을 삭제하면 공감 기록을 지우고 대상 UUID도 교체한다. 재등록한 새 나눔에 이전 공감이 붙지 않는다. 본문 수정이나 통독 완료 체크는 기존 공감을 보존한다.
- 공감은 나눔 수정 시간에 영향을 주지 않으므로 메뉴의 새 나눔 알림을 만들지 않는다. 기존 30초 자동 갱신과 포커스 갱신으로 다른 회원의 공감 수도 반영한다.

## 검증
- 성경통독 관련 32개 테스트 통과(세션·입력·동일 출처·공감 중복/취소·익명 응답·버튼 상태).
- 소스 TypeScript 검사 통과.
- 운영 DB에 `20261113030000_bible_sharing_empathy.sql` 적용 완료. 에디터 화면의 전체 31줄을 준비 파일과 대조한 뒤 실행했다.
- 후속 조회 결과: 누락된 sharing_id 0, 공감 기록 0, RLS 활성, anon/authenticated 직접 SELECT 권한 없음, 초기화 트리거 1개.
- 기존 통독·나눔 내용 및 실제 공감 기록을 임의로 변경하지 않았다. 위 검증은 스키마/권한 확인이며 실제 운영 UI에서 공감 생성/취소 검증은 배포 후 남아 있다.

최신 앱 배포에는 앞서 승인된 목양지·달력·로그인·설치 안내 변경도 포함한다. 여러 심방 등록용 별도 마이그레이션은 아직 운영 미적용 상태다.
