# 모바일 여백 및 성경·찬송가 선택 화면 · 2026-11-12

공통 page-spacing.css에서 일반 메뉴와 관리자 화면의 좌우 여백을 관리합니다. 휴대폰에서는 양쪽 20px을 확보하며, 기기의 안전 영역이 더 크면 그 값을 사용합니다. 각 페이지가 따로 차감하던 너비를 공통 틀에 맞춰 이중 여백을 방지합니다. 기존 페이지별 최대 너비와 홈의 한 화면 메뉴 높이는 유지합니다.

코드 검토 범위:
- 메뉴 선택: menu-home
- 공지 목록·상세, 기도요청, 심방요청, 내 정보, 부관리자: shell
- 오늘의 생일: birthdays-page
- 성경통독: bible-reading
- 성경 찬송가, 찬송가 검색·악보, 성경 본문·통독 본문: scripture-library
- 성경찾기: 독립 화면 양쪽 20px, 위아래 12px 이상의 안전 여백
- 도란도란 목록·글쓰기·댓글: shell community doran
- 마을과 샘: community-directory
- 샘목양지: pastoral
- 2027 사역안내: plan2027-member-page
- 관리자 화면: admin-hub-content 및 admin-shell

성경·찬송가 선택은 휴대폰에서 한 줄에 하나씩, 최소 높이 160px의 큰 카드로 표시합니다. 데스크톱은 두 열과 최소 220px 높이를 사용합니다. 찬송가 목록은 최소 64px 높이로 키웠습니다. 성경의 복사 도구에도 좌우 20px 여백을 확보합니다. 모바일에서 닫힌 메뉴의 그림자와 숨은 링크가 화면에 남지 않도록 정리했습니다.

검증: 수정 TSX의 ESLint, 소스 TypeScript 검사, CSS 파싱 및 git diff 검사 통과. 현재 Work의 로컬 브라우저 사용이 꺼져 있어 실제 기기·브라우저에서의 시각 확인과 운영 배포는 완료하지 않았습니다. 기존 6자리 로그인·로고 수정과 함께 배포할 소스에 포함합니다.
