# 연락처 공개와 성경 복사

- 로그인한 공동체 회원은 구성원의 비밀번호 설정 여부와 무관하게 등록된 연락처를 볼 수 있다. 비로그인 명단 접근 차단과 전화번호 암호화 저장은 유지한다. 디렉터리 조회 시 비밀번호 해시를 조회하거나 검증하지 않는다.
- 성경책과 성경통독이 공통으로 사용하는 본문 복사는 선택 본문을 읽는 순서대로 나열하고, 마지막에 출처를 한 번만 덧붙인다. 연속된 절은 `(창 1:3-7)`, 떨어진 절은 `(창 1:3,7)`, 장·권에 걸친 선택은 `(창 1:31; 2:1-2; 출 1:1)`로 표기한다.
- 클립보드 접근 실패 시 수동 복사용 입력칸에도 같은 형식을 사용한다.

검증: 디렉터리·연락처 복사·성경 복사 관련 29개 테스트 통과. 소스 TypeScript 검사 통과.
