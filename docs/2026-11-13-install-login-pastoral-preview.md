# 설치·첫 로그인 안내와 샘리더 작성 미리보기

## 변경
- 설치 안내에서 사용 중인 기기에 맞는 세 단계만 표시한다. 설치 이벤트가 준비돼 있으면 기존 앱 설치 버튼에서 브라우저 설치창을 바로 열고, 안내 중 이벤트가 준비되어도 설치창 열기 버튼을 표시한다.
- 앱 내 브라우저에는 링크 복사 → 휴대폰 브라우저 열고 주소창에 붙여넣기 → 홈 화면에 추가의 세 단계만 안내한다. Android는 Chrome·삼성인터넷, iPhone은 Safari를 표시한다. 브라우저 직접 실행 링크는 제거했다. 복사는 고정 공개 주소만 사용하고 실패 시 수동 복사 가능한 주소를 보여준다. 홈 화면 앱 실행 중에는 설치 버튼을 숨긴다.
- 웹사이트가 확인 없이 홈 화면 아이콘을 강제로 생성할 수는 없다. 실제 설치는 브라우저·운영체제의 확인 과정이 필요하다. Android/iOS 실기기 설치 검증은 별도로 필요하다.
- 첫 로그인 비밀번호 칸 placeholder에 휴대폰 번호 입력을 명시하고, 바로 아래 강조 안내와 하이픈 제외·변경 비밀번호 안내를 표시한다.
- 관리자 목양지 화면에 `/admin/pastoral-reports/preview` 링크를 추가한다. 전체 관리자만 접근하고 실제 샘·명단과 샘리더 공통 ReportEntry 양식을 사용한다. 미리보기에서는 제출 버튼 비활성화와 submit 함수 가드로 저장을 막는다. 샘 변경 시 입력 상태를 새로 시작한다. 실제 샘리더의 작성·제출 권한은 변경하지 않는다.

## 검증
- PWA·목양지 관련 35개 테스트 통과.
- 소스 TypeScript 검사 통과.
- 현재 운영 관리자 계정이 회원용 목양지 페이지에서 관리자 관리 화면으로 이동하는 동작 확인.
- 새 미리보기와 로그인·설치 UI는 Vercel 파일 업로드 한도로 아직 미배포. 달력 수정과 함께 다음 배포에 포함.
- 별도 검토 이미지 `outputs/pastoral-leader-form-preview.png`는 기존 작성 양식의 필드와 흐름을 옮긴 가상 이름 예시이며 운영 화면 캡처가 아니다.
