# 같은 날짜에 여러 심방 신청·확정 일정

- 앱 내부 심방 신청은 다른 신청/확정 일정이 있는 날짜도 선택하고 제출할 수 있다. 접수는 requested 상태이며 관리자 수락은 기존대로 필요하다.
- 목사님의 직접 등록은 같은 날짜에 여러 건 confirmed 상태로 등록한다. 일정 날짜 변경도 기존 일정 유무로 막지 않는다.
- 관리자 달력은 find로 첫 일정만 찾던 부분을 여러 일정 전체를 표시하도록 변경했다. 취소·대기 상태는 확정 달력에 표시하지 않고 기존 관리 목록에서 확인한다. 기존 신청 가능 기간·명시적 휴무 설정 및 과거 날짜 신청 제한은 유지한다.
- 날짜와 시간은 중복 등록을 허용한다. 목회자가 최종 시간을 조정한다.

## 배포 순서
1. `drizzle/20261113020000_multiple_visits_per_date.sql` 적용: 기존 기록을 삭제하지 않고 날짜별 unique 인덱스를 일반 인덱스로 대체한다.
2. 최신 앱 배포: 날짜 선택/신청 서비스와 관리자 달력 수정 포함.
3. 여러 신청·확정 일정·날짜 변경·수락 권한을 운영에서 점검한다. 실제 등록 내역에 허위 일정은 만들지 않는다.

현시점 Vercel 파일 업로드 한도로 소스·마이그레이션만 준비했다. 운영 DB 마이그레이션은 아직 적용하지 않았고, 앱도 미배포다. 기존 앱의 날짜 제한은 운영 반영까지 남는다.

검증: 심방 관련 90개 테스트 통과. 소스 TypeScript 검사 통과.
