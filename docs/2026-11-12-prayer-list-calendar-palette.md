# 기도목록·심방 달력·메뉴 색 배열

기도요청 안에 기도요청/기도목록 탭을 추가했습니다. 새 요청은 비공개·공개·무명 중 하나를 고릅니다. 기본값과 기존 글은 비공개입니다. 비공개는 본인과 목사님 관리자만 조회합니다. 공개는 로그인한 구성원에게 본문과 이름을, 무명은 본문과 ‘무명’ 표기만 전달합니다. 관리자는 기도목록에서도 모든 범위의 본문과 실제 이름을 봅니다. 부관리자에게 관리자용 기도 열람 권한을 추가하지 않습니다. 개인 댓글은 공개 목록에 포함하지 않습니다.

신규 목록은 /api/prayer-requests/list에서 세션 역할에 따라 서버 SQL로 행과 이름을 제한합니다. 작성자 ID는 응답하지 않고 페이지당 20건을 전달하며 private no-store 캐시 정책을 유지합니다. 기존 개인 요청·관리자 상세 API의 접근 제한을 유지합니다.

심방 달력에서 날짜 칸의 신청/신청 불가/지난 날짜 등의 보이는 상태 문구와 범례를 제거합니다. 날짜 숫자는 남기고 과거 칸만 검정 10% 투명도의 회색으로 표시합니다. 신청 가능 여부와 접근성 설명은 유지합니다. 관리자 일정 내용은 기존대로 표시합니다.

메뉴 아이콘은 빨강→노랑→파랑→분홍을 순서대로 반복합니다. 메뉴 순서를 바꾸지 않고 데스크톱 4열과 모바일 2열 모두에서 규칙을 유지합니다. 글씨는 검정, 아이콘 배경은 각 색의 옅은 톤, 선은 대비를 확보한 진한 톤입니다.

배포 전 drizzle/20261112020000_prayer_visibility.sql 적용이 필요합니다. 기존 기도내용을 공개로 변경하는 UPDATE는 없습니다. 권한·가시성 API 테스트 11개 통과, 관련 회귀 테스트 133개 통과 후 테스트의 SQL 범위 검증식 한 곳을 교정해 재검증했습니다. 소스 TypeScript 검사 통과.
