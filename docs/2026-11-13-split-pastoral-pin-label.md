# 승인된 목양지 분리 작성과 간편비밀번호 안내

사용자가 2026-11-13 검토 이미지를 확인하고 이대로 작업하도록 승인했다.

## 최종 동작
- 샘목양지에 샘모임 / 샘원 나눔·소식 두 작성 화면을 둔다. 각각 별도 제출하며 한 화면의 제출로 다른 화면의 작성 내용을 초기화하지 않는다.
- 샘모임은 날짜·시간·장소·참석자만 입력한다. 참석자는 소속 샘 명단에서 복수 선택한다. 체크박스나 체크 아이콘 없이 이름 행의 배경색과 글씨 굵기로 선택을 표시한다.
- 개인 기록은 이름 목록에서 한 사람을 선택하고 그 사람의 나눔·기도제목·소식 칸만 표시한다. 다른 이름으로 전환할 때 입력 중인 개인별 내용은 해당 작성 화면 안에 보존하며 제출한 사람의 임시 내용만 비운다.
- 기존 원자적 제출·재시도 ID를 사용하며 서버가 담당 샘과 작성자, 날짜를 결정한다. 참석자 ID와 개인 기록 ID는 소속 명단으로 검증하고 표기 이름도 서버에서 채운다.
- 제출 JSON에 entryKind와 attendeeIds를 추가한다. 새 DB 테이블이나 목양지 마이그레이션은 필요 없다. 기존 통합 목양지는 계속 열람·수정·TXT 출력할 수 있다. 목록·상세·TXT에는 새 제출 종류를 구분한다.
- 관리자용 샘리더 작성 미리보기도 같은 두 화면을 사용하며 제출을 막는다.
- 간편 로그인 화면의 입력란 위와 접근성 이름에 ‘간편비밀번호 6자리’를 명시한다. 이름+비밀번호 화면에도 처음에는 전화번호, 이후에는 간편비밀번호 6자리라는 안내를 넣는다.

## 검증 및 배포
- 관련 Vitest 164개 통과.
- 기존 목양지 정책·수정·리더 연결 Node 테스트 68개 통과.
- 소스 TypeScript 검사 통과.
- 실제 휴대폰 UI 및 운영 저장 검증은 미배포 상태이므로 아직 수행하지 않았다. 기존 결합 양식을 전제로 한 disposable-DB E2E 스크립트는 이번에 실행하지 않았다.
- Vercel 업로드 한도 확인 후 최신 묶음 배포가 필요하다. 심방 여러 건 기능에는 별도 `20261113020000_multiple_visits_per_date.sql` 마이그레이션이 필요하며 현재 운영 DB에는 미적용이다.
